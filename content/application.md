## 2. 参加申込

### 2.1. 参加枠・資格

JOLには2つの参加枠（{{< icon flag 選抜 >}}，{{< icon circle-notch オープン >}}）があります．

{{% table class="list-like" %}}

| 枠 | 参加資格 | 代表選抜 |
| --- | --- | --- |
| {{< icon flag 選抜 >}} | 制限あり | 対象 |
| {{< icon circle-notch オープン >}} | 制限なし | 非対象 |
{{% /table %}}

- {{< icon flag 選抜枠 >}}の参加資格は「次のIOL個人戦の時点で20歳未満かつ大学教育を受けていないこと」とします．  
  {{< icon flag 選抜枠 >}}の参加者は国際大会（APLO, IOL）の日本代表選抜の候補になります．
- {{< icon circle-notch オープン枠 >}}はJOLのみの参加になりますが，参加制限はありません．大学生や20歳以上の方のご参加をお待ちしています．

{{% simplebox "補足" %}}

- 海外の予選を受験する場合は{{< icon flag 選抜 >}}枠で参加することはできません．{{< icon circle-notch オープン >}}枠で参加することはできます．
- 国籍は問いませんが一次選抜ではすべての問題が日本語で出ます．
- Q. 現在学校に在学していませんがまだ大学には入っていません．選抜枠で参加できますか？  
  A. 20歳未満であれば学校に在学していなくても選抜枠で参加することができます．
- Q. 受験生ですが選抜枠で参加できますか？  
  A. 可能です．ただし一次選抜を通過した場合でも，大学に入学するとAPLO, IOLへの出場資格は失われます．
- Q. 高専生は選抜枠で参加できますか？  
  A. 高専1年生から3年生までは高校生相当とし選抜枠への参加資格を持つものとします．高専4年生以上は大学生相当とし選抜枠への参加資格を持たないものとします．
- Q. 小学生でも選抜枠で参加できますか？  
  A. 可能です．少し難しいかもしれませんが，チャレンジを歓迎します！

{{% /simplebox %}}

### 2.2. 受験料

参加枠に関わらず，一人3000円の受験料がかかります．受験者登録をした後，12月18日までに応募システムの案内に従ってお支払いください．

支払いは受験料支払い用のサイト（Stores）で行います．利用可能な決済手段と手数料は，支払い時に表示される案内をご確認ください．

{{% simplebox "補足" %}}

受験料は国際言語学オリンピックの登録費等の補助に使われます．登録費は大会への参加費，現地での移動，宿泊，食事代をカバーするものです（大会開催国までの渡航費は含まれません）．例年1人あたり約10～17万円の登録費がかかります．以前は通常の渡航費に加えて登録費も全額代表の自己負担となっていました．IOL2022，IOL2023，IOL2024，IOL2025，IOL2026は受験料をもとに代表の登録費を全額補助することができました．

{{% simplebox "当日の流れについての補足" %}}

- 競技開始前は30分程各自での準備のために見積もってください．
- 競技は15:00に終了します．{{< icon circle-notch オープン >}}枠の参加者はその時点で解散です．
- **{{< icon flag 選抜 >}}枠の成績上位者のうち，無作為に選ばれた数%以下の方には，オンラインで追加面接を実施します．**{{< icon flag 選抜 >}}枠の全参加者に，競技終了15分後（15:15）までに，面接対象者であるかどうかを通知します．面接の対象とならなかった参加者はその時点で解散です．面接対象者には合わせて面接の開始時間など必要な情報を通知しますので，指定された方法で追加面接に参加してください．面接対象者が面接に欠席した場合には失格とします．当日の面接は16:30までに終了しますが，必要な場合には時間調整のうえ，追加で面接を行う可能性があります．

{{% /simplebox %}}

{{% simplebox "準備についての補足" %}}

- JOLはオンラインでの競技になります．問題は本サイトを通じてpdfで配布され，解答はGoogle Spreadsheetを通して集めます．したがって，ネット環境と，問題を閲覧し解答を編集するためのデバイスが必要です．
- 問題pdfは競技中，印刷したり，pdf編集ツールを用いて書き込んだり，ページ内検索したりして構いません．プリンターやpdf編集ツールがあると便利です（必須ではありません）．ただし，**外部資料の参照は禁じます．**
- 競技1週間前までに，オンライン競技の動作確認・練習用サイトを用意します．あらかじめ動作確認，練習をして当日の競技に臨んでください．
- 競技に参加する場所は問いません．競技中に移動しても構いません．たとえば問題の印刷のためにコンビニなどへ行っても構いません．

{{% /simplebox %}}

{{% simplebox "不正行為について" %}}

- **JOL2027では，前年より不正抑制措置を強化しています．**
- 競技者本人が，他者の助けを得たり，外部資料を参照したりすることなく参加してください．
- [{{< icon flag 選抜枠 >}}] 不正行為が疑われる場合，所属校にその旨を通知するなどの処置を取ります．
- [{{< icon flag 選抜枠 >}}] 不正行為が疑われる場合には追加調査を行う可能性がありますが，追加調査に協力しなかった場合は失格とします．
- [{{< icon flag 選抜枠 >}}] たとえJOLで巧妙に不正しても，APLOに出場してよい成績を取らなければJOLの上位の賞を取ることはできません（「3.3. 表彰と選抜の基準」参照）．

{{% /simplebox %}}

{{% simplebox "今後の情報更新について" %}}

- 12月15日以降，応募者向けに競技当日のより詳しい案内をいたします．
- ご質問は委員会 {{< email >}} 宛てにお問い合わせください．

### 3.3. 表彰と選抜の基準

{{< icon flag 選抜 >}}枠については上記を踏まえつつ，以下のように定めます．

- APLOに参加するためには，JOLで上位1/6+α人に入る必要があります（αはJOLで満点に近い点を取った人数．α人ずらすことで，競技が簡単すぎたり，高得点の不正行為者がいたりしても，一定のレベルの正当な参加者がAPLOに招待されます）．
- **APLO招待者のJOL賞については，JOLの成績ではなく，APLOの成績に基づいて決定します．**
- APLOは二段階で採点されます．まず日本委員会独自の基準による採点（独自採点）で評価します．独自採点の結果に基づいてJOL最優秀賞，金賞，銀賞，銅賞を決定します．一定の点以下のものには銅賞を授与し，それ以上のものには金賞と銀賞をおおよそ1:2の人数比になるように授与します．上位3名には最優秀賞を授与します．地区別上位には地区別表彰を実施します．
- 独自採点の上位数十名（おおよそ金賞範囲）についてはさらにAPLOの国際的な基準による採点（正規採点）を行い，その結果をAPLO賞の決定とIOL2027日本代表選抜に用います．

- 敢闘賞: 他の賞を取っていない参加者のうち，いずれかの問題で優秀な成績を修めたもの．

## 4. IOL代表に選ばれたら

IOLまでの間に合同練習会と渡航などについて説明するオリエンテーションをオンラインまたは対面で行います．

合同練習会では過去の大会経験者を交えて一緒に問題を解きながらお互いの知識や解き方を教え合ったり，言語調査を行っている研究者の方を招いて講義を受けたりします．7月には，アジア合同練習会が原則オンラインで開かれ，韓国，インド，香港，台湾，オーストラリアなどの代表たちを交えてレクチャーが行われます．Discord（チャット）を用いた国際交流も盛んに行われます．

IOL開催国までの派遣費（渡航費・宿泊費・添乗員費用など）とIOL登録費（2.2. 受験料を参照）がかかります．あらかじめご了承ください．IOL登録費については補助をします（参加者数不足の場合は一部自己負担となる場合があります）．

IOL2027はタイのバンコクで開催されます．

{{% simplebox "派遣費の額と支払時期" %}}

- 2019年の韓国大会の場合，20万円程度．
- 2022年のマン島（イギリス王室属国）大会の場合，40万円程度．
- 2023年のブルガリア大会の場合，40万円程度．
- 2024年のブラジル大会の場合，45万円程度．
- 2025年の台湾大会の場合，10万円程度．
- 2026年のルーマニア大会の場合，40万円程度．
- 2027年のタイ大会の場合，推定15万円程度．

支払い期限はAPLOまでに提示します．期限までに支払いのない場合，最終選抜であるAPLOの成績に基づいて次点の候補者を代表に繰り上げます．

{{% /simplebox %}}
